Production denoising is never just a filter. A usable system has to move
multi-layer EXR data through algorithms, CPU and GPU backends, frame sequences,
render-farm jobs and artist-facing tools while keeping one consistent data
model. DMX is being built as that common layer, so a new method can be added
without rebuilding the pipeline around it.
